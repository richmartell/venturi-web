# venturi-web

Holding page for venturi-ac.com. A minimal Laravel app: one route, one Blade view (`resources/views/home.blade.php`), no database, no frontend build. Deploys to Laravel Cloud from `main`.

Brand assets come from the Venturi brand book v0.2 (`~/Dropbox/Venturi/Brand/`). Edit the view, push to `main`, Laravel Cloud redeploys.
